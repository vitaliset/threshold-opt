\noindent This supplement reports the per-dataset means $\pm\,1$ standard error
of the mean across the ten seeds of the binary and multiclass empirical
campaigns described in the main dissertation. Each row is a (model, strategy)
combination and each column is an objective (cost matrix or maximization
metric); cells whose mean$\,\pm\,$SE interval overlaps the best strategy's
interval in that column are bolded to mark this within-$1$-SE overlap (a
descriptive within-cell summary; see the experimental-analysis chapters of the
main dissertation for the inferential framing at $\alpha = 0.05$). Datasets are
ordered within each subsection by sample size: small ($N < 10^3$), medium
($10^3 \leq N < 10^4$), large ($N \geq 10^4$).

\section{Base-model prediction concentration}\label{app:model-vertex}

The two tables below report, for each base estimator, the mean
Euclidean distance from a held-out predicted probability vector to its
nearest simplex vertex. The quantity summarizes how sharply the
estimator concentrates its predicted probabilities: values near zero
indicate near-deterministic predictions pinned to a vertex, while
larger values indicate probability mass spread more evenly across
classes. It has no better or worse direction and is reported as a
descriptive companion to the calibration tables.

The threshold_opt library

example.pypip install threshold-opt
import numpy as np
from sklearn.ensemble import RandomForestClassifier
from threshold_opt import metrics, multiclass_strategies as ms
C = np.array([[ 0, 1, 1],       # C[i, j]: cost of predicting j when the truth is i
              [10, 0, 1],       # missing class 1 costs 10
              [ 5, 5, 0]])
model = RandomForestClassifier().fit(X_train, y_train)
rule = ms.FullMatrixPartitioningStrategy(model, use_cv=True)   # 5-fold CV
rule.fit(X_train, y_train, C)
for y_pred in (model.predict(X_test), rule.predict(X_test)):     # argmax, then tuned
    print(metrics.calculate_empirical_risk(y_test, y_pred, C))
  • It follows the scikit-learn interface: fit, then predict.
  • It adds the multiclass partition strategies; scikit-learn tunes binary thresholds only (B7).
  • Every experiment of the dissertation uses it, and its tests run in continuous integration.
  • It is open source, on PyPI and GitHub: vitaliset/threshold-opt.
  • Every strategy of the dissertation is one pip install away.
  • One interface: fit the decision layer on held-out data, then predict.
  • The multiclass partition layer is what scikit-learn does not have.

Machine-checked proofs

The mathematical results of the dissertation are stated and proved in Lean 4 with Mathlib (Appendix E). The Lean kernel checks every proof, and the proofs use only the three standard axioms.

The formalization was generated with AI assistants (Appendix F). No program checks that each formal statement matches the printed one; that match was checked with AI assistance.

Stating the results formally revealed errors in the committee version; the next slide lists them.

Corrections since the committee version

  • Theory (B20, B21). Unconstrained Voronoi rules are exactly the full-matrix rules; the committee version described them as an intermediate class. The bounds now state their logarithmic factors and conditions.
  • Descriptions (B22). The text now describes the G-Mean that the code computes. For $K \neq 3$ the Custom cost is Asymmetric $10\times$, so that matrix is counted twice. The text now says that the relative excess risk falls with $K$.
  • Numbers in the prose. Some win rates in the text of Chapters 8 to 10 differ by one to four points from the charts; no ranking changes.

No experiment was rerun. Pull requests in the public repository apply the corrections step by step. The final version will rerun the Custom cost for every $K$ and recompute the win rates with one rounding rule.

  • Theory: Voronoi equals the full matrix; the bounds are stated correctly.
  • Descriptions now match what was run; the prose numbers will be recomputed.

Limitations and next steps

Limitations

  • One protocol, default hyperparameters, tabular data with $K \leq 10$, and a descriptive comparison.
  • The split proportions are arbitrary, and they favour the cross-validated tuners: calibrators are fitted on the $10\%$ split and the cross-validated tuners use the $80\%$ pool.

Next steps

  • Data beyond tables: images, text.
  • Costs that depend on the instance, such as a payment amount.
  • Tuning the base classifiers.
  • The effect of the class imbalance, varied with the rest fixed.
  • Cross-validated calibrators.
  • The computational cost of each method.

We plan to organize some of these into a paper.

  • Main limits: one protocol, default hyperparameters, a descriptive comparison, arbitrary split proportions.
  • Next: other data, instance-dependent costs, tuned classifiers, the imbalance ratio, cross-validated calibrators, compute cost.
  • A paper should organize these.
